# Day 15 – Stored Procedures & Triggers

## Overview
This project implements database-level automation using
stored procedures and triggers.

---

## What is a Stored Procedure?
A stored procedure is a reusable block of SQL logic
stored inside the database.

---

## What is a Trigger?
A trigger automatically executes when a table
is modified.

---

## Features Implemented
- Money transfer procedure
- Automatic transaction logging
- Trigger to prevent negative balances

---

## Why This Matters
Used in:
- Banking systems
- Payment gateways
- ERP & financial software

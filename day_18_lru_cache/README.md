# Day 18 – LRU Cache System

## Overview
This project implements a Least Recently Used (LRU) cache
using HashMap + Doubly Linked List.

This is how high-performance systems store frequently
accessed data.

---

## Why Caching is Important
Used in:
- Databases
- Browsers
- Web servers
- APIs
- Operating systems

---

## How It Works
- HashMap → O(1) lookup
- Doubly Linked List → track usage order
- Oldest item is removed first

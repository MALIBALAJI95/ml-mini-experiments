# Day 16 – Database Normalization (1NF → 3NF)

## Overview
This project demonstrates how to convert an unnormalized
database into Third Normal Form (3NF).

---

## Why Normalization?
- Removes redundancy
- Prevents anomalies
- Improves data integrity

---

## Normal Forms Implemented
- UNF (bad design)
- 1NF
- 2NF
- 3NF

---

## What I Learned
- Functional dependencies
- How to break tables properly
- Real-world schema design
